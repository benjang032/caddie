# Tensions

Thirteen live contradictions. Open this file when two playbooks disagree. Do not pick the side of whichever chapter was opened first.

| Id | Decision | When A wins | When B wins |
| --- | --- | --- | --- |
| T1 | Where tool schemas live | Freeze a small stable catalog in prefix order (`02:register-static-tool-schemas-once`) when the model is not trained to read mid-history tools. | Append discovered schemas after the trajectory and pin them (`04:append-schemas-once-then-pin`) once the catalog is large enough that prefix edits bust cache or selection accuracy. Measure TTFT and tool-pick accuracy. Mutation is forbidden in both cases. |
| T2 | Compress, isolate, or keep raw | Isolate bulky work in a child first (`02:isolate-bulky-exploration-in-subagents`). | Compress the model-facing window in batch near the cap (`02:trigger-batch-compress-near-eighty-percent`). Never compress the evidence log (`03:trajectory-is-append-only`). Never full-rewrite a formal artifact (`09:stop-full-rewrite-context-collapse`). |
| T3 | Reconcile at write vs append at read | Write-time ADD/UPDATE/DELETE when the fact is one mutable slot and a bad overwrite is cheap to see (a home address). | Append dated claims and fuse at read when two statements can both be true under different conditions (`03:mem0-v3-append-and-retrieve`). Derived status bars may replace. |
| T4 | SFT first vs skip SFT | SFT when parse rate is low or protocol wobbles (`08:stabilize-format-before-reward`). | Skip SFT when success is already nonzero (`08:skip-sft-only-if-success-is-nonzero`). RL needs pass@k support and reward variance. Diagnose foundation vs protocol vs policy first. |
| T5 | Reuse eval for training | Share environment code, generators, and verifiers (`07:validator-as-reward`). | Never share questions or template families (`08:share-env-code-not-eval-tasks`). Headline the held-out score. |
| T6 | How thick the harness should be | Keep a layer until a retirement eval with the layer off passes (`11:delete-internalized-layers`). | Annotate every layer with the model failure it hides (`11:harness-as-weakness-log`). No harness claim is portable across models (`05:harness-thickness-tracks-model-strength`). |
| T7 | Add a second agent | Split for information the producer could not have had (`10:information-gain-test`), or for context economy (`02:isolate-bulky-exploration-in-subagents`). | Do not split for text-only debate over the same evidence (`10:debate-information-bottleneck`). |
| T8 | Which reviewer | Peer-strength model from another family for open plans (`04:pre-approve-irreversible-ops-across-model-families`). | Small sidecar on structured fields for live admission. Weak judge may filter training data and must never become the demonstrator (`08:weak-verifier-can-teach-a-strong-explorer`). Panel for an open rubric (`07:heterogeneous-multi-judge`). |
| T9 | Ask first vs proceed | Ask when architecture, data, permissions, public interfaces, or wide blast radius are at stake (`05:requirement-clarification-gate`). | Low-risk reversible work states the assumption and proceeds (`09:scoped-clarification-not-always-ask`). Measure interruption rate next to deviation rate. |
| T10 | Human silence | Silence may pick a reversible conservative default (`04:hitl-timeouts-defaults-and-priority-channels`). | Silence may never authorize an irreversible act (`01:escalate-on-caps-and-irreversible`). Grade the path by reversibility first. |
| T11 | Satisfaction vs compliance | Hard thresholds on rule breaks, leaks, unsupported claims, and unauthorized ops (`09:guardrails-override-satisfaction`). | Score false refusal among runs that already cleared those thresholds (`01:layered-guardrails-plus-false-refusal`). |
| T12 | Repair a trajectory vs refuse | Production may repair pairings so the session stays valid (`06:events-placeholder-never-fake` still forbids fake success). | Collection mode must not repair, because a placeholder poisons SFT (`05:trajectory-integrity-repair`, `08:keep-failures-out-of-positive-sft`). Flag the record before repair. |
| T13 | Pay for a semantic index | Prose with synonym drift pays for dense plus rerank (`03:when-to-pay-for-structure`). | Code defaults to pattern and path search until a measured recall gap appears (`05:embedding-index-tradeoff`). |

A3 still holds in every row. Append. Never splice.
